그린파인더

휴대폰 GPS로 핀까지 거리와 클럽별 샷 거리를 재는 도구예요. 정확한 측정을 위해 위치 권한을 허용해주세요.

GPS 오차는 보통 ±3~10m예요. 정밀 거리측정기가 아닌 참고용으로 사용하세요.

해결법: 사파리 주소창 왼쪽 "AA" 아이콘 → 웹 사이트 설정 → 위치를 "허용"으로 변경 후 새로고침. 그래도 안 되면 설정 → Safari → 고급 → 웹 사이트 데이터에서 이 사이트를 지우고 다시 열어주세요.
